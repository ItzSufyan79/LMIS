# SIH26246 — LMIS

**Labour Market Intelligence System** — frontend prototype for job hirers, HR teams and recruiters.

Compares open roles against job-ready talent by district and trade, forecasts the gap, and gives
explainable hiring actions.

See [`frontend/README.md`](frontend/README.md) for how to run it, the screen hierarchy, the map
service and the data model.

```
SIH26246-LMIS/
└── frontend/          # Vite + React + Tailwind v4 (the whole prototype)
```

Backend, ML, GIS and data-engineering folders are intentionally absent — this submission is the
frontend only, with a deterministic mock data layer standing in for the API.
